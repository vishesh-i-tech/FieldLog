# Workspace Rules: FieldLog

1. **Always Respond in English**: Regardless of the prompt language (Hindi/Hinglish/etc.), always answer in English.
2. **Phased Development**: Proceed in structured, modular phases with immediate verification.
3. **Continuous Git Pushes**: Automatically stage, commit, and push updates to `origin main` to keep the GitHub contribution history active.
4. **Quick Response Time**: Do not block chat responses on Git network wait times.
5. **Maintain `explainer.md`**: Continuously keep architecture and technical explainer up to date.
6. **Assign Field Officer to Each Site**: Every site card must show assigned field officers and provide seamless reassignment.
7. **Modal Input Stability**: Always use sibling backdrop touchables behind bottom sheets/modals to avoid input focus dismissal on React Native Web.
